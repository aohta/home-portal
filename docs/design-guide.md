# Portal のデザイン

`kintai-kanri` の `docs/design-guide.md` と `apps/web/src/assets/tokens.css` を基準にします。
トークンは同じ値をコピーし、実行時・ビルド時に隣のリポジトリへ依存しません。

- 白のコンテンツ、薄いグレーのページ背景、主要操作のバイオレット `#6250c9`。
- ヘッダー下のバイオレットの境界、最大幅1200px、8px単位の余白。
- 本文16px、付随情報14px、操作領域48px。カード12px、操作部品8pxの角丸。
- 必要な Element Plus の部品と CSS だけを読み込み、セマンティックトークンに対応付ける。
- 48rem未満ではアプリと機器を1列にする。320px幅でも主要操作を維持する。
- 日本語の見出し・操作ラベルを使い、機器の状態は色と文言で示す。
- 黒のフォーカス枠と黄色のハロー、本文へのスキップリンク、見出しの順序を保つ。
- 文字拡大、キーボード、動きの抑制、強制配色に対応する。

アプリへのリンクと観測値を主題とし、挨拶や装飾用のダッシュボード数値は置きません。
アプリの稼働状態は測定していないため、リンクに稼働中の表示を付けません。
機器の「受信済み」は5分未満の観測がある意味で、常時接続や現在の値を保証しません。
表示更新時刻と観測日時を分け、API の取得失敗後は前回の値であることを通知します。
時刻は日本時間で表示します。

ストレージには空き容量・全体容量・使用済み容量と収集日時を表示します。
収集から15分以上経過した結果、個別収集先の取得不能、API の取得失敗を区別します。
表示更新と収集は独立しているため、再読み込みでサーバー上の容量収集は実行しません。

右矢印は勤怠アプリと同じデジタル庁デザインシステムの SVG 原本を使用します。
出典・利用規約は [アイコンの README](../apps/web/src/assets/icons/digital-agency/README.md) を参照してください。
